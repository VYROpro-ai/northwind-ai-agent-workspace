# Changelog

All notable changes to this template are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-10-29

### Added
- 101 screens across 12 areas: auth & onboarding, home, agents, chat, workflows, runs & approvals,
  knowledge, integrations, analytics, admin, billing, account & system pages.
- Design-token system (7 primitive scales, semantic light/dark tokens, type scale, radius, elevation).
- Runtime light / dark / system theme with no flash on load.
- Component library: UI primitives, AI components (messages, composer, tool calls, reasoning, citations),
  SVG charts, 180 icons.
- Global ⌘K command palette and notifications drawer.
- Responsive app shell with off-canvas navigation below 1024 px.
- Screen index (`/screens`) and living design system (`/design-system`).
